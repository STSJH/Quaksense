🌍 QuakeSense — Live Earthquake Monitor

QuakeSense is a lightweight, responsive web application that displays recently reported earthquakes using the U.S. Geological Survey (USGS) real-time earthquake feed.

The project is designed as an educational information tool. It does not provide emergency earthquake warnings or predict earthquakes.

✨ Features
🌐 Live earthquake data from the USGS
📊 Displays the number of events currently loaded
📈 Shows the largest reported magnitude
🕐 Displays the latest feed refresh time
📍 Lists recent earthquake locations, times, and magnitudes
🔄 Automatic refresh every 60 seconds
🔘 Manual Refresh Now button
📱 Responsive design for desktop and mobile
⚡ No backend or database required
🛰️ Data Source

QuakeSense uses the USGS Earthquake Hazards Program's real-time GeoJSON feed.

https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/2.5_day.geojson


The current version retrieves M2.5+ earthquakes reported during the previous day.

🗺️ Activity Map

The current map is an illustrative activity display. The red and yellow points do not represent the actual locations of the earthquakes.

The earthquake information shown in the event list comes directly from the USGS feed.

⚠️ Important Safety Notice

QuakeSense is not an earthquake early-warning system.

A normal browser cannot reliably detect local earthquakes by itself. Genuine earthquake detection requires calibrated seismic instruments and a network of sensors.

This website is intended for educational and informational purposes only and should not be used for emergency decisions.
